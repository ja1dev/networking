Terminal labs

Real CLI practice in your browser. Each lab is a small network of IOS-style routers and switches and VPCS PCs, with a live topology diagram. You configure it at the console exactly as you would in EVE-NG, and every task is checked against what the network actually does: a ping only succeeds if your VLANs, trunks, routes and ACLs really let it through.

What the simulator covers

Simulated: user/privileged/config modes with ? on any word or at the end of a line, Tab completion (interface names too), abbreviations with IOS's ambiguity errors, no and do, | include/exclude/begin/section, extended ping, debug ip icmp; interfaces, subinterfaces, loopbacks, secondary addresses, speed and duplex; VLANs, access ports, 802.1Q trunks with native and allowed VLANs, and DTP; spanning tree (PVST+ and Rapid PVST+, root election, root primary/secondary, port cost and priority, PortFast, BPDU guard, native-VLAN and port-type inconsistencies); EtherChannel (LACP, PAgP and on, suspended members, port-channel config); port security (maximum, static and sticky MACs, protect/restrict/shutdown, err-disable and recovery); router-on-a-stick; switch SVIs and default gateways; static, default and floating static routes; OSPFv2 with areas, DR/BDR, timers, passive interfaces, costs, default-information originate and static redistribution; EIGRP in classic and named mode (K values, DUAL with feasible successors, variance, wide metrics, static redistribution); NAT (static, dynamic pools, PAT on an interface or pool); HSRP v1 and v2 (priority, preempt, timers, authentication, interface tracking); IPv6 (global, EUI-64 and link-local addresses, SLAAC, static routes, OSPFv3); standard and extended ACLs with match counters; DHCP server and relay; console and VTY passwords, local users, SSH and telnet; CDP, MAC, ARP and IPv6 neighbour tables; ping and traceroute; saving, reload and the matching show commands for all of it.

Not simulated: MST, VTP, BGP, RIP, OSPF multi-process, NSSA and stub areas, route summarisation, IPv6 ACLs, EIGRP for IPv6, VRRP and GLBP, QoS, wireless and real timers (everything converges instantly). Use EVE-NG or the workbook labs for those. Commands outside the list answer with the usual % Invalid input, just as an IOS image without the feature would.
